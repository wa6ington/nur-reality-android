# Reality Composer для Android

Аналог Apple Reality Composer для Android (Kotlin + Jetpack Compose + Google Filament / SceneView + ARCore).

## Возможности
- **Галерея проектов**: создание, дублирование, удаление, сохранение в JSON и экспорт сцен (`.rcscene.json`).
- **Типы якорей**: Горизонтальный, Вертикальный, Изображение, Лицо.
- **3D-редактор**: интерактивная орбитальная камера, 3D-сетка и оси, визуальный гизмо выделения, привязка к сетке, Отменить / Повторить (Undo/Redo).
- **Библиотека объектов**: Куб, Сфера, Цилиндр, Конус, Капсула, Плоскость, 3D-Знак, готовые наборы (Арка, Стол, Маяк) и импорт собственных 3D-моделей `.glb` / `.gltf`.
- **Инспектор свойств**: позиция, поворот, масштаб, палитра цветов, PBR-материалы (Матовый, Глянцевый, Металл, Пластик, Резина, Металличность/Шероховатость), физика (Динамический / Неподвижный, Бетон / Дерево / Резина / Лед / Свинец, форма коллизии).
- **Визуальные поведения (Triggers & Actions)**:
  - Триггеры: Нажатие, Старт сцены, Близость к камере, Столкновение.
  - Действия: Переместить, Повернуть, Изменить масштаб, Акцент (Прыжок, Всплеск, Оборот 360°, Тряска, Мигание), Вращение по орбите, Скрыть, Показать, Пауза, Звуковой сигнал, Сменить сцену.
- **Режим «Играть»**: симуляция физики и поведений в реальном времени с автоматическим возвратом сцены после остановки.
- **AR-режим (ARCore)**: размещение сцены на реальных поверхностях через ARCore, а также безопасный виртуальный AR-режим для эмулятора Android Studio.

## Запуск в Android Studio
1. Откройте папку проекта `3D VIEWER FOR ANDROID` в **Android Studio** (`File -> Open`).
2. Дождитесь синхронизации Gradle.
3. Выберите эмулятор (рекомендуется Pixel с API 30–35 и **Google Play**, в настройках камеры AVD можно выбрать **VirtualScene** для тестирования ARCore).
4. Нажмите **Run ▶**.
